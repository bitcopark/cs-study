## 📚 Study Topics

* **운영체제 (Operating System)**
  * 프로세스와 스레드, CPU 스케줄링, 동기화, 메모리 관리, 가상 메모리, 파일 시스템 등
* **컴퓨터구조 (Computer Architecture)**
